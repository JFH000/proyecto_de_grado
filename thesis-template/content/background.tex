\chapter{Background}
\label{chap:background}

This chapter presents the ideas on which the rest of the thesis rests, and only those.
Section~\ref{sec:bg-v2v} explains why vehicles that share a channel disturb each other, and why staying
silent has a cost. Section~\ref{sec:bg-rl} explains how an agent learns by trial and error, as each \ac{V2V}
pair does in this thesis. Section~\ref{sec:bg-marl} explains what changes when many agents learn at once, in particular which
reward each one should learn from, the subject of RQ2. Section~\ref{sec:bg-fl} presents federated learning,
first with a central server and then without one, the subject of RQ1.

\section{Interference, rate, and delay}
% Lo mínimo de comunicaciones inalámbricas para entender el modelo: interferencia, SINR y tasa, y por qué quedarse callado llena la cola.
\label{sec:bg-v2v}

A \ac{V2V} pair that reuses the uplink channel of a \ac{CUE} transmits at the same time and on the same
frequencies as that user. Each signal therefore reaches the other receivers as \termdef{interference}: the
pair disturbs the \ac{CUE} at the \ac{BS}, the \ac{CUE} disturbs the receiver of the pair, and pairs on the
same channel disturb each other.

A receiver can decode a signal if the signal stands out above the interference and the \termdef{noise}, a
random thermal disturbance present in every receiver. This is measured by the \ac{SINR}, which in turn sets
the highest rate at which the link can carry data \cite{shannon48communication}:
\begin{equation}
  \mathrm{SINR} = \frac{P\,h}{\sigma^2 + I}, \qquad R = W \log_2\bigl(1 + \mathrm{SINR}\bigr)
  \label{eq:bg-sinr}
\end{equation}
\begin{wherelist}
  \item $P$ is the transmit power, and $h$ is the \termdef{channel gain}, the fraction of that power that
    reaches the receiver; it falls with distance and fluctuates randomly from one millisecond to the next,
    an effect called \termdef{fading};
  \item $\sigma^2$ is the noise power, and $I$ is the sum of the powers received from the other transmitters
    on the same channel;
  \item $R$ is the rate in bits per second, and $W$ is the bandwidth of the channel in hertz.
\end{wherelist}
Since powers span many orders of magnitude, they are written in \termdef[decibel]{decibels}: a ratio $x$ is
$10 \log_{10} x$~dB, and a power in dBm is measured relative to \SI{1}{\milli\watt}. The maximum transmit
power in this thesis, \SI{23}{dBm}, is about \SI{200}{\milli\watt}. In the links of this thesis,
interference, not noise, limits the rate: for a pair \SI{25}{\meter} apart, a single \ac{CUE}
\SI{250}{\meter} away on the same channel lowers the \ac{SINR} from about \SI{46}{dB} to about
\SI{16}{dB}. More power therefore helps a pair's own link but hurts every other link on its channel.

A transmitter stores the data it generates in a \termdef{queue} and sends them as fast as its rate allows.
If data arrive faster than the link transmits them, the queue grows, and a pair that stays silent only
accumulates data. By \termdef{Little's law} \cite{little61queuing}, the average queue $Q$, the arrival rate
$\lambda$, and the average delay $D$ satisfy $Q = \lambda D$, so bounding the delay is the same as bounding
the queue. With data arriving at \SI{1}{Mbps} and a limit of \SI{100}{\milli\second}, the queue may not
exceed \num{100000} bits, which a silent pair reaches after \SI{100}{\milli\second}.
Chapter~\ref{chap:system-model} writes these quantities for every link of the scenario.

\section{Reinforcement learning}
% Cómo aprende un agente por ensayo y error: retorno y factor de descuento, función Q y exploración epsilon-greedy; Q-learning, DQN y D3QN se remiten a Sutton y Barto, Mnih et al. y al capítulo 5.
\label{sec:bg-rl}

In \ac{RL}, an \termdef{agent} learns to make decisions by interacting with an \termdef{environment}
\cite{sutton+18rl}. At each time step $t$, the agent observes the \termdef{state} $s^t$, chooses an
\termdef{action} $a^t$, and receives a \termdef{reward} $r^t$, a number that says how good the action was;
the environment then moves to a new state $s^{t+1}$. The rule that maps states to actions is the
\termdef{policy} of the agent. Nobody tells the agent which action is correct: it must find out by trying.
In this thesis, each agent is a \ac{V2V} pair that observes its channels and its queue and chooses a channel
and a transmit power. Formally, this setting is an \ac{MDP}: the next state and the reward depend only on
the current state and action, not on the earlier history.

The agent does not seek the best immediate reward, but the best discounted sum of rewards, called the
\termdef{return}:
\begin{equation}
  G^t = \sum_{j=0}^{\infty} \gamma^{j}\, r^{t+j} \label{eq:bg-return}
\end{equation}
\begin{wherelist}
  \item $r^{t+j}$ is the reward received $j$ steps after step $t$;
  \item $\gamma \in [0, 1)$ is the \termdef{discount factor}, which gives less weight to later rewards.
\end{wherelist}
The discount factor sets how far ahead the agent looks: roughly $1/(1-\gamma)$ steps, that is, about 100
steps with $\gamma = 0.99$ and about 10 with $\gamma = 0.9$. This choice matters in this thesis: with
$\gamma = 0.99$, our agents forget much of what they learned when exploration ends
(Appendix~\ref{apx:diagnosis}).

To decide, the agent estimates the \termdef{Q function}, $Q(s, a)$: the expected return of taking action $a$
in state $s$ and acting well afterwards. An agent that knew this function would simply pick, in each state,
the action with the largest value. \termdef{Q-learning} \cite{watkins+92qlearning} learns this function from
experience, and a \ac{DQN} \cite{mnih+15dqn} approximates it with a neural network; we refer to
\citet{sutton+18rl} and \citet{mnih+15dqn} for both. The agent of each \ac{V2V} pair, as in
\citet{li+22fedmarl}, is a \ac{D3QN}: a \ac{DQN} with four further improvements, trained with the Adam
optimizer \cite{kingma+15adam}. Chapter~\ref{chap:proposed-architecture} describes it.

To discover which actions are good, the agent must also try actions it does not yet believe are the best.
With the \termdef[epsilon-greedy policy]{$\varepsilon$-greedy} policy, the agent picks a random action with
probability $\varepsilon$, and otherwise the one with the highest estimated value. Training starts with
$\varepsilon = 1$ and lowers it gradually to a small floor.

\section{Multi-agent reinforcement learning}
% Qué cambia cuando aprenden varios agentes a la vez: no estacionariedad, asignación de crédito y agente perezoso, alineación frente a facilidad de aprendizaje de la recompensa, y CTDE frente a DTE.
\label{sec:bg-marl}

In \ac{MARL}, several agents act in the same environment, and the outcome for each of them depends on what
all of them do \cite{gronauer+22marlsurvey,nguyen+20madrl}. In the \ac{V2V} problem, the \ac{SINR} of a pair
depends on the channels and powers chosen by every other pair. At each step, each agent
$k \in \Kset = \{1, \dots, K\}$ chooses its own action $a_k^t$, and the environment responds to the
\termdef{joint action} of all of them. Each agent sees only part of the state, its \termdef{observation}
$o_k^t$. When the agents cooperate toward a common reward under these conditions, the problem is called a
\ac{Dec-POMDP}; Chapter~\ref{chap:system-model} formulates the \ac{V2V} problem in this way.

Besides partial observability, the number of joint actions grows exponentially with the number of agents:
with 10 agents of 60 actions each, there are $60^{10} \approx 6 \times 10^{17}$. Two further difficulties
matter most for this thesis \cite{gronauer+22marlsurvey,nguyen+20madrl}:
\begin{description}
  \item[Non-stationarity.] While one agent learns, the others change how they act. From the point of view
    of each agent, the environment keeps changing its rules \cite{delafuente+24gametheory}.
  \item[Credit assignment.] When all the agents receive the same reward, none of them knows how much of it
    its own action caused. An agent may be rewarded for what another did, or punished for the mistake of
    another. It may even stop learning, because its own exploration would lower a reward that the others
    already earn: the \termdef{lazy agent} of \citet{sunehag+18vdn}.
\end{description}

Credit assignment can be analyzed through two properties of the reward that each agent receives
\cite{wolpert+01collectives,agogino+08rewards}. \termdef{Alignment} is the degree to which improving the
reward of the agent also improves the objective of the system. \termdef{Learnability} is the degree to which
that reward depends on the actions of the agent rather than on those of the others.
Table~\ref{tab:bg-rewards} compares three kinds of reward. A \termdef{global reward}, the same for all the
agents, is aligned but hard to learn, and it gets harder as agents are added. A \termdef{local reward},
which measures only what concerns each agent, is easy to learn but may be poorly aligned. A
\termdef{difference reward}, which measures how much the performance of the system changes because the
agent is there, is designed to have both properties, but it requires evaluating the system without each
agent. The individual reward that this thesis proposes is a local reward in this sense: it measures what the
action of the agent can change, even though one of its terms comes from the \ac{BS}.
Section~\ref{sec:pa-individual-reward} discusses how much alignment it gives up.

\begin{table}[htbp]
  \centering
  \caption[Alignment and learnability of three kinds of reward]{Alignment and learnability of three kinds
    of reward \cite{wolpert+01collectives,agogino+08rewards}.}
  \label{tab:bg-rewards}
  \begin{tabularx}{\linewidth}{@{}l >{\raggedright\arraybackslash}X >{\raggedright\arraybackslash}X@{}}
    \toprule
    Reward & Alignment & Learnability \\
    \midrule
    Global & Perfect: it is the objective of the system & Low, and it falls as the number of agents
      grows \\
    Local & Can be poor: an agent may improve its reward by harming others & High \\
    Difference & Aligned by construction & Higher than that of the global reward \\
    \bottomrule
  \end{tabularx}
\end{table}

Cooperative methods also differ in where training and execution happen \cite{amato24cooperative}. In
\ac{CTDE}, the agents use information from all of them while they learn, but each one acts only on its own
observation. In \ac{DTE}, each agent learns and acts on its own; the classic example is
\termdef{independent learners}, which run their own Q-learning and ignore that the others exist
\cite{tan93independent,claus+98dynamics}. In this thesis, \ac{DTE} also names the reference method in which
each agent learns alone and shares nothing. Federated learning lies in between: each agent still trains its
own network from its own experience, but the agents periodically share and combine their weights.

\subsection{With a central server: FedAvg}
% La idea de entrenar sin mover los datos, la fórmula de FedAvg, el FRL horizontal y el costo del servidor central.

In \ac{FL}, a model is trained with data spread across many participants, without the data leaving the place
where they were generated \cite{mcmahan+17fedavg,kairouz+21advances}. The most widely used algorithm,
\ac{FedAvg} \cite{mcmahan+17fedavg}, works in \termdef[round]{rounds}. In each round, the server sends the
\termdef{global model} to the participants, each participant trains its copy with its own data and sends the
resulting weights back, and the server combines them with a weighted average:
\begin{equation}
  \vtheta_{\mathrm{g}} = \sum_{k=1}^{K} \frac{n_k}{n}\, \vtheta_k , \qquad n = \sum_{k=1}^{K} n_k
  \label{eq:bg-fedavg}
\end{equation}
\begin{wherelist}
  \item $\vtheta_k$ are the weights of participant $k$ after its local training, and $n_k$ is the amount of
    data with which it trained, so that a participant that trained with more data weighs more;
  \item $\vtheta_{\mathrm{g}}$ is the global model, from which every participant continues training.
\end{wherelist}

Applied to reinforcement learning agents, the same idea is called \ac{FRL} \cite{qi+21frl}: each agent learns
from its own experience, and the agents periodically average their networks, so that each one receives part
of what the others learned in situations it did not live through. When all the agents have the same kind of
states and actions, the setting is called \termdef{horizontal federated reinforcement learning}. The setting
of this thesis is close to it, with one difference: in the textbook case, each agent has its own copy of the
environment, while here all the pairs share one environment and interfere with each other
(Chapter~\ref{chap:related-work} returns to this point). Federation has also been proposed as a way to cope
with non-stationarity \cite{xu+22mafrl}. Sharing does not always help, though: this thesis finds cases in
which averaging with all the agents is no better than not sharing at all (Section~\ref{sec:res-gossip}). In
the scheme of \citet{li+22fedmarl}, the participants are the \ac{V2V} pairs, and the server is the \ac{BS}.

The server has a cost. With $K$ participants, it receives $K$ models and sends the average back to all $K$,
so it takes part in all $2K$ transfers of a round. It is a single point of failure, it becomes the
communication bottleneck as participants are added, and every participant must trust it
\cite{kairouz+21advances,ge+24dfl}.

\subsection{Without a server: gossip}
% Grafo de comunicación entre vecinos, la regla de gossip, el consenso y su velocidad, y el costo del nodo más cargado.
\label{sec:bg-dfl}

In \ac{DFL}, there is no server: the participants exchange models directly with some of the others
\cite{kairouz+21advances,ge+24dfl}. Who can talk with whom is described by a \termdef{graph}. Each
participant is a \termdef{node}, and two nodes are joined by an \termdef{edge} if they can communicate. The
\termdef{neighbors} of node $k$, $\Nset_k$, are the nodes joined to it, and their number, $|\Nset_k|$, is the
\termdef{degree} of the node. A node with no neighbors is \termdef{isolated}, and a graph is
\termdef{connected} if there is a path of edges between any two of its nodes. In a wireless network, two
nodes are neighbors if they are close enough; such a graph is a \termdef{random geometric graph}, the model
of a wireless network used by \citet{boyd+06gossip}. In this thesis, two \ac{V2V} pairs are neighbors if their
transmitters are at most \SI{300}{\meter} apart. Since the positions are drawn anew in each episode, the
graph changes from one episode to the next. Figure~\ref{fig:bg-fedavg-gossip} compares the two
communication patterns.

In a \termdef{gossip algorithm}, each node replaces its value with an average of its own value and those of
its neighbors \cite{boyd+06gossip}. With equal weights, one round is
\begin{equation}
  x_k \leftarrow \frac{1}{1 + |\Nset_k|} \Bigl( x_k + \sum_{j \in \Nset_k} x_j \Bigr)
  \quad \text{for every node } k \label{eq:bg-gossip}
\end{equation}
\begin{wherelist}
  \item $x_k$ is the value of node $k$ before the round; in federated learning, it is the vector of weights
    of its model.
\end{wherelist}
All the nodes average at the same time, with the values from before the round, and an isolated node keeps
its value.

If the graph is connected, repeating this rule brings all the nodes to a common value: the graph reaches
\termdef{consensus}. This also holds if the graph changes from round to round, as long as, over time, it
connects all the nodes \cite{olfatisaber+07consensus,boyd+06gossip}. Knowledge, however, advances only one
neighbor per round. In \ac{FedAvg}, whose graph is a star, a single round brings everyone to the average. Gossip gives up that speed in exchange for not depending on a
central node. Between rounds, each node trains on its own data, and the communication of the busiest node
depends on its number of neighbors, not on the total number of nodes \cite{lian+17dpsgd}.
Chapter~\ref{chap:related-work} reviews decentralized schemes of this kind.
